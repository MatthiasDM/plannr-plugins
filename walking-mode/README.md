# Walking mode (`walking-mode`)

Walk through a model in first person, with every editing tool still at hand. A browser-only plugin (no
engine): `walking-mode/web/index.ts`.

**Install:** download `plannr-plugin-walking-mode-<version>.plannr-plugin` from the
[releases](https://github.com/MatthiasDM/plannr-plugins/releases) and pick it in **Plugins → Manage plugins… →
Install from file**; switch it off or remove it in the same dialog.

- **Desktop:** click the view to lock the mouse (as in a game): the mouse looks and steers, **W A S D** move,
  **Shift** runs, the wheel steps up and down, and a click acts at the crosshair with the active tool.
  **Esc** unlocks: the cursor is back and clicks work as usual; right-click (or the button in the bar)
  locks again. **⌥ + a letter** picks a tool.
- **Touch:** a joystick moves, a one-finger drag looks, a tap acts with the tool, on-screen buttons change storey.
- With the Construction plugin it walks storey by storey at eye height above each floor.
